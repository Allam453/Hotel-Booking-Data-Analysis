# 🏨 Hotel Booking Data Analysis

## 📌 Project Overview
This project analyzes hotel booking data using Python, SQL, and Power BI to uncover booking trends, customer behavior, and business insights.

## 🎯 Project Objectives
- Clean and preprocess hotel booking data.
- Perform Exploratory Data Analysis (EDA).
- Analyze business questions using SQL.
- Build an interactive Power BI dashboard.
- Generate actionable business insights.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI

## 📂 Project Files
- 📓 Python Notebook (.ipynb)
- 🗄️ SQL Queries (.sql)
- 📊 Power BI Dashboard (.pbix)
- 📑 Presentation (.pptx)
- 📁 Raw & Cleaned Dataset

## 📈 Dashboard KPIs
- Total Bookings
- Total Revenue
- Average Daily Rate (ADR)
- Cancellation Rate
- Average Stay Duration

## 💡 Key Insights
- Direct bookings have lower cancellation rates.
- Resort Hotels achieve higher ADR.
- Summer has the highest booking volume.
- Longer lead times increase cancellation probability.
